題名：
- `Routability-Driven Floorplanning of Analog and Mixed-Signal Circuits`

重點：
- thesis 專注在 mixed constraints 下的 routability-driven placement / floorplanning。
- 提出兩種方法：
  - sequence pair
  - polish expression
- 用 module expansion 依 net congestion probability 改善 routability。
- 同時處理 symmetry、alignment、boundary、preplace、abutment、range、maximum separation 等 constraints。

對本題可用：
- congestion 驅動 soft block enlargement 這個想法非常貼近 feedthrough 擴張。
- 表示法選擇會影響後續可加入多少幾何限制。

可落地成：
- 對 soft block 定義：
  - base area
  - FT-induced extra area
  - resized width/height within aspect ratio
