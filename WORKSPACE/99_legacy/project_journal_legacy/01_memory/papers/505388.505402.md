# 505388.505402

原文：
- [505388.505402.pdf](/mnt/d/Bili/PD/FINAL/505388.505402.pdf)

題名：
- `Routability Driven Floorplanner with Buffer Block Planning`

重點：
- 傳統 floorplanner 只看 area 已不夠，必須提早考慮 interconnect delay、routability、buffer planning。
- 方法採 two-phase simulated annealing。
- Phase 1 先以 area / wirelength 做粗優化。
- Phase 2 再把 area、wirelength、congestion、routability 一起評估。
- 使用 probabilistic analysis 估計 congestion。
- buffer 位置不是任意，插入間距有約束。

對本題可用：
- 直接借 `two-phase` 架構。
- 把 channel / FT 當成類似 buffer resource feasibility 的概念處理。
- 用期望 demand，而非單一路徑，估計 channel 壓力。

可落地成：
- 初始解階段先求合法 outline/block placement。
- 第二階段再評估 route / channel / FT 成本。
