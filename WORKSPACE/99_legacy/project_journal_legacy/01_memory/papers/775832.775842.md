題名：
- `Improved Global Routing through Congestion Estimation`

重點：
- 用 amplified congestion estimate 去引導 rip-up and reroute。
- 相較既有方法，可大幅降低 overcongested edges 與 wirelength。
- 證明 congestion map 的塑形方式，會直接影響最終 routing 品質。

對本題可用：
- 對反覆爆滿的 channel 增加額外 cost amplification。
- 不要每輪都用原始 demand map；可引入歷史壅塞記憶。

可落地成：
- `historical_congestion[channel] += overflow`
- routing cost 使用 `base + lambda * historical_congestion`
