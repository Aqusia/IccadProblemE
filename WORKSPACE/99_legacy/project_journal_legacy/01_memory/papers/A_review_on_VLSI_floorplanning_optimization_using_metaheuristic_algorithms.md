題名：
- `A Review on VLSI Floorplanning Optimization using Metaheuristic Algorithms`

重點：
- floorplanning 是 NP-hard。
- representation 會直接影響 search space 與轉換複雜度。
- 整理了 slicing / non-slicing / B-tree / sequence pair 等表示法。
- 比較 SA、PSO、ACO 等 metaheuristic。

對本題可用：
- baseline 首選 SA，因為穩定、易插入複合 cost。
- 若要擴展，先選對表示法，再談演算法。

可落地成：
- 第一版可不追求最強表示法，先用容易維護的 rectangle move 模型。
